# CRUD Project (Products)

A products manager: add, update and delete products from a table.

**Live demo:** https://mostafa-98.github.io/Crud-Project/

## Built with

HTML, CSS, vanilla JavaScript

## Features

- Create, read, update and delete products
- Form validation (name must start with a capital letter, price range check)

## Run locally

Open `index.html` in your browser. No build step needed.
